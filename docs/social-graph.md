# Социальный атлас

Откройте [social-graph.html](social-graph.html) в браузере. Вкладка **Правила системы** сразу показывает каталог текущей сборки: цели, шаги плана, потребности, события, зарегистрированные обработчики событий и слухов, ответы игрока, коллективные планы, черты и воспоминания. Поиск и список слева охватывают все узлы; граф показывает связи выбранного узла, а справа видны тип связи и модуль обработчика. Узел обработчика подписан событием и этапом исполнения, а не именем лямбды компилятора. Он отличается от `NpcReaction` — отложенного ответа NPC, который изображён только в общем цикле. Узел «Планировщик» связывает цели с доступным набором операторов, но конкретный маршрут зависит от состояния мира.

Чтобы увидеть жителей из Read Records, экспортируйте сохранение из корня репозитория:

```sh
sh tools/social-graph-export.sh /path/to/save.dat /path/to/social-save.json
```

Затем нажмите **Открыть экспорт save** и выберите `social-save.json`. Для автоматической загрузки при открытии страницы экспортируйте сохранение в `docs/social-graph-save.js`: `sh tools/social-graph-export.sh /path/to/save.dat "$PWD/docs/social-graph-save.js"`. Этот файл содержит частную историю NPC и исключён из Git. Поддерживаются те же `.dat` и `.sav` архивы, которые читает Read Records. Экспорт читает отдельную секцию `ResidentRecords`, не восстанавливает игровую сессию и не меняет сохранение. Если архив восстановлен из старого save, страница обозначает его как частичный.

Во вкладке **Люди и события** выберите NPC по имени или фракции. Узлы соединяют выбранного NPC с другими сохранёнными жителями, которые упомянуты в его записях. Нажмите **линию**, чтобы отфильтровать общие события; нажмите **имя NPC**, чтобы открыть его собственный граф. Хронология справа показывает текст записи, ход, вид события, идентификатор истории и доступные причинные ссылки. Вид события открывает его зарегистрированные обработчики в каталоге. Переход по причинной ссылке ищет только событие, реально сохранённое в архиве.

Связи на графе жителей показывают **записи о совместных событиях**, а не текущее числовое отношение. Read Records не хранит моментальные `Feeling`, `Trust`, `Fear` и другие значения для каждого отношения. Очевидец, участник и слушатель слуха могут иметь разные знания об одном событии; отсутствие записи не доказывает, что событие в мире не произошло.

Нажмите **Ход** в хронологии, чтобы увидеть сохранённые значения осей NPC после этого хода и изменение относительно предыдущего доступного снимка. Старые сохранения без снимков показывают сообщение об отсутствии данных. Под записью события перечислены лишь возможные поздние влияния через память и черты по каталогу; это не доказательство, что они произошли у выбранного NPC.

Во вкладке **Правила системы** фильтры показывают события без специального обработчика и сохраняемые слухи без отдельного правила. Это сведения о регистрации, а не ошибки: событие может сохраняться в архиве или вызывать память, а слух всё равно проходит через общую систему знаний. Направленный граф показывает входящие связи слева, исходящие справа; связь от обработчика к этапу означает, **когда** он исполняется, а не какой результат гарантирован. На графе показаны первые восемь соседних узлов каждого направления; полный список остаётся в правой панели. На узком экране граф прокручивается горизонтально, сохраняя читаемый размер подписей.

Кнопка **Самый интересный NPC** открывает жителя с максимальным баллом Read Records среди результатов текущего поиска. Балл показан в карточке справа.

После изменения контентных модулей обновите встроенный каталог:

```sh
sh tools/social-graph-export.sh
```

Это перезапишет `docs/social-graph-data.js`, который страница загружает и при открытии через `file://`. Экспорт save уже содержит каталог сборки, из которой выполнена команда. Формат JSON имеет `schema: 1`, массивы `nodes`, `edges`, `residents` и поля `turn`, `partial`; новые поля добавляйте совместимо с существующим HTML. Для проверки используйте `npc/social-graph-export`, затем полный Docker test и e2e при изменении страницы или запуска игры.
